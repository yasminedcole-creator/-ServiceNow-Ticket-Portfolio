### 📝 Issue Reported
User reported that the Sharp MFP printer stopped working mid-shift after 
functioning normally all day. Printer displayed an error when attempting 
to print. A member was at the counter waiting for a printed document, 
making this time-sensitive.

### 🔍 Troubleshooting Steps
1. Contacted user Jonathan Meridian via phone
2. Instructed user to navigate to Settings → Printers & Scanners and confirm Sharp MFP is set as default printer
3. Had user open the print queue and clear all stuck/pending jobs
4. Instructed user to power cycle the printer – full shutdown, waited 60 seconds, powered back on
5. Had user reseat the ethernet cable on the back of the printer
6. Printer returned to Ready status after restart
7. User submitted a test print – job completed successfully
8. User confirmed member document printed without issue

### ✅ Resolution
Issue resolved by clearing the stuck print queue and power cycling the 
Sharp MFP printer. Ethernet cable reseated to restore network connectivity. 
Printer returned to Ready status. User confirmed successful print of member 
document. No hardware replacement required. User advised to clear print 
queue and power cycle as first troubleshooting step if issue recurs 
before contacting IT.
